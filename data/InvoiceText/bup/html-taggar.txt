<u>	Understruken text	<u>Understruken</u>

<span>	Formatering med CSS	<span style="color:blue">Blå</span>

<sup>	Upphöjd text	m<sup>2</sup>

5. CSS med span
För <span> finns stöd för följande CSS-egenskaper enligt dokumentationen:
CSS-egenskap	Funktion	Exempel
color	Textfärg	color:red
background-color	Bakgrundsfärg	background-color:yellow
font-size	Teckenstorlek	font-size:12pt
font-weight	Fetstil	font-weight:bold
font-family	Teckensnitt	font-family:Arial

Exempel:
<span style="color:red; font-size:12pt; font-weight:bold;">
    Nu äre' slut.
</span>


Observera att stödet för CSS är begränsat och kan variera med JasperReports-versionen.
